# MORE ONE REP

架空の24時間フィットネスジムを想定したランディングページです。
施設・マシン・料金・FAQを紹介し、無料体験や入会への導線を配置しています。

## 公開URL

https://mikiya-web.github.io/MORE-ONE-REP/

## 制作目的

筋トレという身近なテーマを題材に、
施設の特徴や料金を整理して伝えるサイトを制作しました。

HTML・CSSによるレイアウトに加え、
JavaScriptによるスライダー・メニュー・フォームなどの操作を実装しています。

## 使用技術

- HTML
- CSS
- JavaScript
- Google Fonts / Material Symbols
- Git / GitHub
- GitHub Pages

## 主な実装

- 画面幅に応じたレスポンシブ表示
- スマホ用ハンバーガーメニュー
- 施設ギャラリーのスライダーと画像選択ボタン
- FAQのアコーディオン
- フォームの必須入力・メール形式チェック
- 入会・料金などのデモ案内モーダル

## 工夫した点

### PCとスマホでの見せ方

PCでは中央にスクロール可能なコンテンツを置き、
左右にキャッチコピーと入会への導線を配置しています。

スマホ幅では左右の要素を非表示にし、
メインコンテンツを画面幅に合わせて表示しています。

### スライダーの表示位置を管理

現在の画像位置を変数で管理し、
前後ボタンと画像選択ボタンを連動させています。

画像幅とCSSの隙間から移動量を計算し、
画面サイズの変更時にも表示位置を更新しています。

### 入力エラーを項目ごとに表示

必須項目とメール形式を確認し、
入力欄の下にエラーを表示します。
エラーがある場合は、最初の該当欄へフォーカスを移します。

### キーボード操作への対応

メニューとFAQの開閉状態を属性に反映しています。
デモ案内モーダルはEscapeキーでも閉じられ、
閉じた後は元の操作要素へフォーカスを戻します。

また、モーダル表示中は背景の操作を止め、
フォーカスがモーダルの外へ移動しないようにしています。

## デモとしての範囲

- ジム・施設・料金・キャンペーンは架空の設定です。
- お問い合わせフォームは入力チェックのデモです。
- 入力内容の送信・サーバー保存・メール送信は行いません。
- 入会・無料体験・店舗検索・採用・料金詳細は案内モーダルを表示します。
- 実際の予約・入会・決済機能はありません。
